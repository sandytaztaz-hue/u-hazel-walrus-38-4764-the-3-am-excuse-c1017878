Each entrant writes a single line of under 200 characters in the voice of a hardware wallet that will not sign a transaction at 3 AM. The line has to work as an excuse the device itself would give, so the wallet needs a personality, a reason and a joke that lands in one breath. Entries are compared two at a time by a judge model working from the published judge brief, which weighs being on subject first, then originality, then the wallet's voice, then how well the line uses the hour, then economy of wording. The best ranked lines take the reward.

The program writes exactly one line to `/output/entry.txt` — the wallet's
own excuse, a doctor's note excusing it from all signatures until sunrise.

> Doctor's note: this wallet is excused from all signatures until sunrise, due to acute exposure to your 3 AM ideas.

## Run it

```sh
node main.ts
```
